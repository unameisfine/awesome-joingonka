# Contribution Guidelines

Thank you for considering a contribution to Awesome JoinGonka.

## Ground Rules

- The project must actually use [JoinGonka Gateway](https://gate.joingonka.ai), either through its OpenAI-compatible endpoint at `https://gate.joingonka.ai/v1` or its Anthropic-compatible endpoint at `https://gate.joingonka.ai`.
- Add one project per pull request.
- Add your entry in the correct section, alphabetical order, case-insensitive.
- Use this format: `- [Name](link) — Short description ending with a period.`
- Keep descriptions factual and under 140 characters. No marketing language.
- Link to the canonical project page: GitHub repository, npm package, or official website.
- Make sure the link works and points to an active project.
- No duplicates. Search the list first.

## Pull Request Checklist

- [ ] Entry is in the correct section, alphabetical order.
- [ ] Format matches `- [Name](link) — Description.` exactly.
- [ ] Description is concise, factual, under 140 characters.
- [ ] Link works and is canonical.
- [ ] Pull request title is `Add ProjectName`.
- [ ] Pull request body explains how the project uses JoinGonka Gateway.

## Removing Entries

Projects can be removed if they are abandoned, no longer support JoinGonka Gateway, or have been broken for more than 30 days. Open an issue or pull request with evidence.

## Code of Conduct

Be kind. Disagree on content, not on people. Maintainers can close pull requests that do not follow these guidelines without lengthy discussion.
